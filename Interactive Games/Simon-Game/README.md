# 🟢 Simon Says — Memory Game

**Simon Says** is a responsive browser-based memory game built with **HTML, CSS, and JavaScript**.

The game displays a sequence of coloured buttons. The player must repeat the pattern in the correct order. Each successful round adds another colour, making the sequence progressively more challenging.

## ✨ Features

* Randomly generated colour sequences
* Increasing difficulty after every successful round
* Keyboard support using **Enter** or **Space**
* Sound effects for button interactions
* Highest score saved using browser local storage
* Responsive layout for mobile and desktop screens
* No libraries or installation required

## 🎮 How to Play

1. Click **Start Game** or press **Enter** or **Space**.
2. Watch the coloured button sequence carefully.
3. Repeat the sequence in the same order.
4. Complete the pattern to advance to the next level.
5. The game ends when an incorrect button is selected.
6. Start again and try to beat your highest score.

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Click **Start Game** to begin.

No installation or development server is required.

The highest score is saved in the browser using **local storage**. It remains available after the page is refreshed unless the browser data is cleared.
