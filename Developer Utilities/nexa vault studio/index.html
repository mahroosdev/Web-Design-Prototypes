Design Principle
Under the Hood
Entropy Engine
Every generation call sources fresh randomness from crypto.getRandomValues(). No session state is reused, no seed is cached. The result is statistically indistinguishable from true random noise.
Strength Calculation
Entropy is computed as H = L × log₂(N) — where L is password length and N is the effective character pool. The live strength meter visualises this in real time as you adjust your configuration.
k-Anonymity Protocol
Breach lookup sends only a SHA-1 hash prefix to Have I Been Pwned when internet is available. The password itself is never sent; offline users can still use local generation and strength scoring.
Session Memory
Generated passwords are held in a transient in-session log — never written to localStorage or cookies. Close the tab and the session is gone. No trace. No recovery. Intentionally ephemeral.
