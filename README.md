# 🎨 Web Design Prototypes

This repository contains a collection of web design concepts, landing pages, portfolio templates, business tools, and developer utilities built using **HTML, CSS, and JavaScript**. Each project is designed to explore different UI styles, layouts, and practical web application ideas while keeping the code lightweight and easy to understand.
